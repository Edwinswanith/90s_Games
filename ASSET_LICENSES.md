# Asset provenance and licenses

## Original project assets

All character meshes, cosmetic shirt patterns, crouching NPCs, courtyard/street layouts, shutters, roofs, benches, bicycle, pots, bunting, trees, chalk grids, stone/sand patterns, podium and confetti are generated by source code in this project. No commercial game models, stock photography, film imagery, brand advertisements or downloaded character assets are used.

The icon in `apps/web/public/favicon.svg` is original project artwork. Game thumbnails in `apps/web/public/thumbnails` are captured from the project's actual playable Three.js scenes by `tests/e2e/capture-performance.mjs`.

Effects and the restrained looping melody are original oscillator synthesis in `apps/web/src/audio.ts`; no external recording, sampled song or audio download is used. English/Tamil game copy is project text based on the supplied specification. Tamil translations are draft and require human review.
